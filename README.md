# BioAlign-Pro: Pairwise Sequence Alignment Engine

BioAlign-Pro is a full-stack, browser-based bioinformatics application dedicated to conducting high-precision Needleman-Wunsch (Global) and Smith-Waterman (Local) sequence alignments. It accurately replicates the rigorous mathematical standards established by EMBOSS Water/Needle and NCBI BLAST engines, ensuring 1:1 gap math parity across DNA and Protein sequences.

## 🧬 Architectural Overview and Codebase Context

This project is built using a decoupled modular architecture designed for high scalability, rapid visual DOM updates, and completely isolated deterministic mathematics routines. 

### 1. Core Mathematical Engine (`/core/`)
The analytical brain of the application. It handles pure data processing and matrices.
- `alignmentEngine.js`: The central orchestrator. It manages the alignment tracebacks, evaluates BLAST statistical calculations (Bit Scores and local Karlin-Altschul E-Values), and acts as the gatekeeper for local vs. global rendering.
- `dpMatrix.js`: Contains the rigorous Needleman-Wunsch / Smith-Waterman algorithms utilizing Double Precision (Float64) mathematical tracking. Enforces strict $> globalMax$ zero-floor filtering to eliminate trailing null-net extensions (EMBOSS parity rule).
- `gap.js`: Contains the affine vs. linear gap penalty configuration logic. Evaluates open vs. extend parameters.
- `scoringMatrix/`: Contains heavily vetted biological substitution protocols like BLOSUM62, PAM250, and EDNAFULL.

### 2. User Interface Controller (`/ui/`)
This module strictly isolates state synchronization and visual rendering from the analytical engine.
- `uiController.js`: Binds DOM elements and intercepts user configuration modifications. Captures manual parameter overrides and forces the underlying state arrays to synchronize.
- `state.js`: The central repository for cross-file parameter synchronization. Handles the complex matrix selection override routes (restricting dropdowns, enforcing mathematical resets, resolving NCBI BLAST vs EMBOSS mode collisions).
- `resultsController.js`: Parses the alignment arrays generated by the core DP matrix and constructs the HTML tracing report (Sequence 1 vs Sequence 2) with embedded alignment metrics.
- `defaults.js`: Default value mappings configured exactly identical to NCBI initial state targets.

### 3. Application Entry & Automation (`/js/` & `package.json`)
- `main.js`: Bootstraps the application by synchronizing the UI controller to the DOM on load.
- `bgAnimation.js`: Natively projected Canvas2D background visuals. Implements biologically derived models tracking the app state: it mathematically computes an organic 3D DNA Double Helix or a Single continuous Protein sequence loop utilizing atomic dots and lines mapping matching thematic RGB arrays (omitting high-cost WebGL). 
- **Build Pipeline**: Powered by `esbuild` and `tailwindcss`. The `npm run build` chain parses `js/main.js` and `css/tailwind.input.css` into the completely self-contained `/dist` folder for rapid static GitHub Pages deployment.

## 🛠️ Development Setup & Build Instructions

BioAlign-Pro is compiled locally but runs fully symmetrically in modern browsers via static file serving. 

### Dependencies
- Node.js environment (v18+)

### Installation
1. Clone the repository.
2. Execute `npm install` to hydrate build dependencies.

### Compilation
The application uses native ES modules locally but compiles into an optimized bundle.
- **Production Build**: Execute `npm run build`. This runs `tailwindcss --minify` and `esbuild --bundle --minify` simultaneously.
- **Local Testing**: Changes in `/css/*` and `/core/*` require a rebuild before they are reflected in the global `dist/main.js`. 

## ⚖️ Precision and Protocols

Any future modifications to `dpMatrix.js` or `alignmentEngine.js` must strictly preserve the following biological rules:
1. NCBI/Linear configurations completely omit the 'Gap Extension' penalty.
2. EMBOSS/Affine configurations necessitate absolute parity with EMBOSS traceback lengths.
3. Smith-Waterman tracking cells strictly enforce `>` matching protocols to isolate true peak alignments natively.
